# Projects are built from a fixed toolkit, not user-defined schemas

Every Project is assembled from a fixed menu of Tools (the Basecamp model), each a purpose-built feature with its own data, plus one generic List tool with custom columns as an escape hatch. We rejected separate Project types because they lock the data model and UI to a few shapes, and fully generic Notion-style blocks because they are slow to build, hard to make feel good, and would have the AI generating schemas instead of filling in plans. Flexibility comes from which Tools a Project turns on.
